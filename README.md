# 视觉引导机械手抓取定位系统（手眼协同方向）

> 基于 C# WinForm + OpenCvSharp 的工业视觉全流程仿真平台，覆盖模拟相机成像、九点手眼标定、双算法视觉定位、PLC 通信仿真、机械手抓取闭环、SQLite 数据管理与生产报表。无真实硬件条件下即可验证算法与流程。

---

## 一、项目解决什么问题

在工业自动化产线中，机械手抓取位置随机变化的工件时，无法依赖固定示教点，必须由视觉系统实时检测工件位置并引导机械手抓取。本项目解决以下核心问题：

1. **手眼坐标转换**：相机输出的是像素坐标，机械手需要的是机械坐标，必须通过手眼标定建立两个坐标系的映射关系
2. **工件视觉定位**：从图像中精确检测工件的中心位置和旋转角度，达到亚毫米级精度
3. **视觉与 PLC 通信**：视觉系统与 PLC 之间通过握手信号协调工作，确保数据同步和流程可控
4. **抓取闭环控制**：从图像采集到机械手抓取的完整流程自动化，包括异常处理和状态复位
5. **生产数据追溯**：检测数据持久化存储，支持历史查询和生产质量统计

由于无真实硬件（工业相机、机械手、PLC），本项目全部采用软件仿真实现，但核心算法、通信协议、流程逻辑与真实工业项目完全一致，后续替换真实硬件只需更换三个仿真类的实现。

## 二、主要功能

| 功能模块 | 说明 |
|---|---|
| **模拟相机** | 模拟 1280×960 工业相机，随机生成 1~3 个矩形金属工件，模拟高斯噪声、光照波动、对比度变化；支持单帧采集和连续采集（FPS 显示） |
| **九点手眼标定** | 基于仿射变换 6 参数模型，9 组对应点构成超定方程组，MathNet 矩阵 QR 分解求解最小二乘解；自动生成仿真九点，显示各点误差和标定参数 |
| **Blob 视觉检测** | 反色阈值分割 + 形态学开运算 + 连通域 + 图像矩；零阶矩求面积，一阶矩求中心，二阶中心矩求主轴方向（角度） |
| **边缘视觉检测** | 高斯滤波 + Canny 边缘 + 形态学闭运算 + 轮廓 + 最小外接矩形（MinAreaRect）；置信度 = 轮廓面积/外接矩形面积 |
| **双算法对比** | 同一帧图像同时运行 Blob 和边缘检测，三色框叠加显示（蓝=Blob、品红=边缘、绿=真值），定量对比位置精度、角度精度、耗时 |
| **视觉引导抓取** | 7 步完整抓取闭环：系统初始化→工件触发→视觉检测→坐标转换→写 PLC→机械手抓取→完成复位；机械手 S 曲线加减速运动，实时显示运动轨迹 |
| **PLC 通信仿真** | 模拟 Modbus 寄存器模型：5 个线圈信号（触发/检测完成/抓取完成/OKNG/报警）+ 6 个保持寄存器（目标 X/Y/角度、当前 X/Y/角度） |
| **机械手仿真** | 模拟四轴 SCARA 机械手，S 曲线加减速运动规划，支持抓取/释放动作，实时位置回调 |
| **历史记录查询** | 基于 SQLite 的检测记录持久化，支持查询最近 50 条记录，显示 ID、时间、机械坐标、角度、OK/NG、位置误差、抓取状态 |
| **生产统计报表** | 累计统计（检测总数、合格数、合格率、抓取成功率）+ 精度统计（平均/最大位置误差、平均角度误差、平均耗时、平均置信度）+ 今日统计 |
| **分级日志系统** | Info/Warn/Error/Fatal 四级日志，文件持久化（按天分割）+ 内存查询，日志目录自动创建 |

## 五、核心模块说明

### 5.1 模拟相机（CameraSimulator）
- 模拟 1280×960 分辨率工业相机，像素当量 0.05mm/pixel，视野 64×48mm
- 随机生成 1~3 个矩形金属工件（随机位置、角度、尺寸 30~60mm × 20~45mm）
- 工件渲染：深灰色主体（灰度 60±10）+ 亮边（灰度 220，线宽 2）+ 中心标记点（灰度 240，半径 4）
- 模拟高斯噪声（σ=8）、光照波动（±15 灰度）、对比度变化（±10%）
- 提供 `WorldToPixel` / `PixelToWorld` 坐标系转换接口
- 接口设计与真实相机 SDK 一致，后续换真实相机只需替换本类

### 5.2 九点手眼标定（HandEyeCalibrator）
- 基于仿射变换 6 参数模型：
  ```
  X = a·x + b·y + c
  Y = d·x + e·y + f
  ```
  其中 (x,y) 为像素坐标，(X,Y) 为机械坐标，a/e 为像素当量，b/d 为旋转夹角，c/f 为原点偏移
- 9 组对应点构成 18 个方程的超定方程组，使用 MathNet 矩阵 QR 分解求解最小二乘解
- 提供标定误差评估：平均误差、最大误差、各点重投影误差
- 标定精度：平均误差约 0.014mm，最大误差约 0.028mm

### 5.3 视觉定位算法（VisionDetector）
实现两套算法，可单独运行也可对比：

**算法 1：Blob 阈值分割 + 连通域 + 图像矩**
- 反色阈值分割（BinaryInv，阈值 120）提取深色工件
- 形态学开运算（3×3 核）去除小噪点
- 连通域分析提取工件轮廓，按面积降序排列
- 零阶矩 M00 = 面积，一阶矩 M10/M01 → 中心坐标
- 二阶中心矩 μ20/μ02/μ11 → 主轴方向：θ = 0.5·atan2(2μ11, μ20-μ02)
- 优势：速度快（0.7~1.3ms），填充区域检测稳定，置信度恒为 1.0

**算法 2：Canny 边缘 + 轮廓 + 最小外接矩形**
- 高斯滤波（5×5，σ=1.5）→ Canny 边缘检测（低阈值 50，高阈值 150）→ 形态学闭运算连接断裂边缘
- 查找外轮廓并按面积筛选（最小面积 500 像素²）
- 对每个轮廓计算最小外接旋转矩形（MinAreaRect），直接获取中心、尺寸、角度
- OpenCV 角度范围 (-90,0]，根据宽高关系转换为标准角度
- 置信度 = 轮廓面积 / 外接矩形面积（越接近 1 形状越规则）
- 优势：亚像素级精度，对光照变化鲁棒

**精度对比（典型值）**：
| 指标 | Blob+图像矩 | 边缘+最小外接矩形 |
|---|---|---|
| 位置误差 | 0.012~0.113mm | 0.010~0.066mm |
| 角度误差 | 0.01~0.21° | 0.01~0.03° |
| 检测耗时 | 0.7~1.3ms | 1.9~3.7ms |

### 5.4 PLC 通信仿真（PlcSimulator）
- 模拟 Modbus 寄存器模型：
  - **5 个线圈信号（Coil，布尔量）**：触发请求(TRIGGER)、检测完成(READY)、抓取完成(DONE)、检测结果(OKNG)、报警(ALARM)
  - **6 个保持寄存器（Register，浮点）**：目标 X/Y/角度、当前 X/Y/角度
- 实现视觉系统与 PLC 的握手信号流程
- 接口与真实 Modbus TCP 一致，后续换真实 PLC 只需替换本类

### 5.5 机械手仿真（RobotSimulator）
- 模拟四轴 SCARA 机械手运动
- S 曲线加减速运动规划（加速度平滑变化，避免启停冲击）
- 支持抓取/释放动作，实时位置回调事件
- 提供当前位置、抓取状态查询
- 原点位置 (0, 0, 0)

### 5.6 数据管理（DatabaseService + LogService）
- **SQLite 数据库**：检测记录持久化，18 个字段覆盖检测全流程；支持增删改查、按日期范围查询、今日查询、生产统计
- **分级日志**：Info/Warn/Error/Fatal 四级，按天分割文件（`log_YYYYMMDD.txt`），内存保留最近 10000 条
- **生产报表**：累计统计 + 精度统计 + 今日统计

## 六、安装方法

### 6.1 环境要求
- **操作系统**：Windows 10/11（WinForm 依赖 Windows）
- **.NET SDK**：.NET 8.0 或更高版本
- **开发工具**：VS Code（推荐）或 Visual Studio 2022

### 6.2 安装 .NET 8.0 SDK
1. 访问 [.NET 官网](https://dotnet.microsoft.com/download/dotnet/8.0)
2. 下载并安装 **.NET 8.0 SDK**（不是 Runtime）
3. 验证安装：
   ```bash
   dotnet --version
   # 输出示例：8.0.424
   ```

### 6.3 获取项目代码
将项目克隆或复制到本地，项目目录结构如下：
```
视觉引导机械手抓取定位系统（手眼协同）/
└── src/
    └── HandEyeVisualGuide/
        ├── Models/
        ├── Services/
        ├── Form1.cs
        ├── Form1.Designer.cs
        ├── Program.cs
        └── HandEyeVisualGuide.csproj
```

### 6.4 还原 NuGet 包并编译
```bash
cd src/HandEyeVisualGuide
dotnet restore
dotnet build
```

编译成功后输出：
```
已成功生成。
    0 个警告
    0 个错误
```

项目会自动还原以下 NuGet 包（无需手动安装）：
- OpenCvSharp4 4.10.0.20240616
- OpenCvSharp4.runtime.win 4.10.0.20240616
- MathNet.Numerics 5.0.0
- Microsoft.Data.Sqlite 8.0.10

### 6.5 运行程序
```bash
dotnet run
```

程序启动后显示主窗体，标题为「视觉引导机械手抓取定位系统 - 手眼协同仿真平台」。

## 七、使用方法

### 7.1 主界面布局
- **顶部工具栏**：打开相机、单帧采集、连续采集、Blob检测、边缘检测、算法对比、视觉引导抓取、查看记录、生产报表、FPS 显示
- **左侧图像区**：实时显示相机图像、检测结果、机械手位置和运动轨迹
- **右侧上方面板**：相机参数（分辨率、像素当量、视野、状态）
- **右侧中间面板**：手眼标定（九点法）—— 标定点列表、标定结果、生成仿真九点、执行标定
- **右侧下方面板**：检测结果（可滚动文本框，显示检测日志、历史记录、生产报表）
- **底部状态栏**：当前操作状态提示

### 7.2 完整操作流程

#### 第一步：打开相机并采集图像
1. 点击「**打开相机**」→ 初始化模拟相机，相机参数面板显示分辨率、像素当量、视野
2. 点击「**单帧采集**」→ 采集一帧带随机工件的模拟图像，左侧显示图像，右侧检测结果显示工件真值信息（中心、角度、尺寸）
3. （可选）点击「**连续采集**」→ 连续采集图像，顶部显示实时 FPS，再次点击停止

#### 第二步：九点手眼标定
4. 点击「**生成仿真九点**」→ 自动生成 9 个标定点（像素坐标+机械坐标配对），标定点列表显示各点坐标
5. 点击「**执行标定**」→ 求解仿射变换 6 参数矩阵，标定结果面板显示平均误差、最大误差和标定参数公式
   - 标定成功后才能进行坐标转换和视觉引导抓取

#### 第三步：视觉定位检测（可选，用于算法验证）
6. 点击「**Blob检测**」→ 运行 Blob+图像矩算法，右侧显示每个工件的像素中心、角度、置信度、耗时、与真值对比的位置误差和角度误差
7. 点击「**边缘检测**」→ 运行 Canny 边缘+最小外接矩形算法，输出格式同上
8. 点击「**算法对比**」→ 同一帧同时运行两套算法，左侧图像三色框叠加（蓝=Blob、品红=边缘、绿=真值），右侧显示对比表格和精度优胜者

#### 第四步：视觉引导抓取闭环
9. 点击「**视觉引导抓取**」→ 执行完整 7 步抓取流程，右侧检测结果实时显示每一步日志，左侧图像动态显示机械手运动轨迹（红色=机械手当前位置，黄色=目标位置，浅蓝色=运动轨迹）
   - 流程：系统初始化 → 工件触发 → Blob 视觉检测 → 坐标转换 → 写 PLC 寄存器 → 机械手 S 曲线运动抓取 → 完成复位
   - 抓取完成后自动将检测记录写入 SQLite 数据库

#### 第五步：数据查询与统计
10. 点击「**查看记录**」→ 显示最近 50 条历史检测记录（ID、时间、机械坐标、角度、OK/NG、位置误差、抓取状态）
11. 点击「**生产报表**」→ 显示完整生产统计报表（累计统计、精度统计、今日统计、数据库文件路径、日志目录）

### 7.3 注意事项
- 执行「视觉引导抓取」前必须先完成手眼标定，否则坐标转换会报错
- 每次「单帧采集」会生成新的随机工件，检测和抓取基于当前帧
- 检测结果区域支持鼠标滚轮滚动查看长日志
- 数据库文件和日志文件自动生成在程序运行目录下（`bin/Debug/net8.0-windows/`）

## 十一、项目亮点

1. **全流程仿真**：从相机成像到机械手抓取的完整工业视觉流程，无真实硬件也能验证算法和通信
2. **双算法对比**：实现 Blob+图像矩和边缘+最小外接矩形两套算法，可定量对比精度、速度和鲁棒性
3. **手眼标定**：基于仿射变换的九点标定，MathNet 矩阵 QR 分解求解最小二乘，标定精度达 0.014mm
4. **PLC 通信**：模拟 Modbus 寄存器模型，5 线圈+6 寄存器，握手信号流程与真实工业现场一致
5. **数据闭环**：检测数据自动入库 SQLite，支持历史追溯和生产统计报表
6. **硬件可替换**：相机、PLC、机械手三个仿真类接口与真实硬件 SDK 一致，后续可无缝替换
7. **多工件匹配**：实现最近邻真值匹配算法，解决多工件场景下检测结果与真值匹配错误的问题

## 十二、后续扩展方向

- **替换真实硬件**：
  - 相机：替换为海康/大华工业相机 SDK，实现真实图像采集
  - PLC：替换为 Modbus TCP 客户端，与西门子/三菱 PLC 通信
  - 机械手：替换为 ABB/发那科/埃斯顿机械手控制器，通过 TCP/IP 或 EtherCAT 控制
- **算法升级**：引入深度学习目标检测（YOLO），支持复杂场景下的工件识别和缺陷检测
- **功能扩展**：增加多相机协同、三维视觉（结构光/双目）、多工件排序抓取
- **界面升级**：开发 Web 端监控界面，实现远程监控和数据可视化
- **性能优化**：增加 GPU 加速（CUDA）、多线程并行处理、自动曝光和自动阈值调整
